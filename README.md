# bpla-coordinate
Программа для полета БПЛА из одной точки виртуального пространства в другую его точку по меткам на python.
Я установила и настроила среду разработки ROS на виртуальной машине "Клевер". Это включает установку необходимых пакетов ROS и настройку рабочего пространства.
Дальше я создала новый пакет ROS для программы управления полетом. После создала скрипт Python с программой управления полетом и сохранила этот скрипт внутри пакета ROS. Далее запустила виртуальный БПЛА в среде "Клевер" и запустила программу управления полетом.
